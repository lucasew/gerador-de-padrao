# Documentation Guidelines

- **Format:** Use standard JSDoc (`/** ... */`) for all functions, classes, and complex logic.
- **Content:**
  - Explain the *why* and the *flow*, not just the *what*.
  - Focus on non-obvious details, edge cases, and side effects.
  - Avoid stating the obvious (e.g., "Returns a string").
  - Ensure documentation matches the current code state (fix drift first).
- **Scope:** One cohesive area per PR.
